Shared interfaces of the return routine of the switcher, binary model

The proofs of switcher_ret_specification_gen (functional specification) and interp_expr_switcher_return (validity of the return entry point) run the same code, in both runs in lockstep. They share the block-group lemmas of switcher_return_blocks_n_binary, which only depend on this file:
  • switcher_return_blocks_1_binary: first part of block 12, pop the topmost frame of the trusted stack,
  • switcher_return_blocks_2_binary: second part of block 12 and blocks 13-15, restore the callee-save registers, clear the stack frame and the registers, and jump back to the caller.
The block-group lemmas start and end at the first address of blocks of the code switcher_instrs, given by switcher_block_offset (see switcher_preamble_binary).
